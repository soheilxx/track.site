## 3. Decisions taken for the implementation

| Topic | Decision | Reason |
| --- | --- | --- |
| Locale prefix | `localePrefix: "always"`; `/` and every unprefixed marketing URL 301 → `/en/...` (query preserved); dashboard/API/CDN paths stay unprefixed | Supplement §7 asks for consistent prefixes incl. `/en` and a deterministic `/` |
| New locales roll-out | `fr, es, it, nl` are added to routing only once their UI catalogs, marketing/legal copy and all 30 articles exist, so no English fallback is ever served on a localized public page. Done 2026-09-04: `ACTIVE_LOCALES` = all six (`apps/web/src/i18n/routing.ts`), `COPY_LOCALES` = all six (a missing copy entry is a compile error, `pick()` never falls back on a public page), parity report strict with zero gaps, localized slugs identical to English for the release (hreflang and the redirect matrix stay simple; the loader supports per-locale slugs later). Withdrawing a locale = removing it from `ACTIVE_LOCALES` only | Supplement forbids mixed-language pages; avoids indexing half-translated locales |
| Tariff catalogue | New package `@track-site/catalog` (pure TS, tested): plans, list prices, entitlements, overage packs, trial, billable-event rules, plan finder + cost calculator. DB `plans` table is synced from it by the seed; Stripe amounts are verified against it by `/api/health` (`amount_mismatch`) | "Preise, Limits oder Feature-Gates dürfen nicht an mehreren Stellen auseinanderlaufen" |
| Plan ids | `starter`, `growth`, `pro`, `enterprise`; `scale` is migrated to `pro` (data migration keeps subscriptions), env names `STRIPE_PRICE_PRO_*` (legacy `STRIPE_PRICE_SCALE_*` still read as fallback and reported as deprecated in health) | Supplement renames the third plan |
| Article slugs | Front matter may set `slug` per locale; `translationGroupId` = the English file name; old `/blog` URLs redirect to the localized new slug | Localized slugs without breaking existing URLs |
| Social cards | Dynamic `opengraph-image` routes (Next `ImageResponse`) per page/article/locale; no static image files | Supplement prefers generated 1200×630 cards over 180 files |
| Living AI Core | Own component, no new rendering dependency; WebGL2 fragment shader with CSS/static fallbacks and a per-user setting persisted in `user` preferences | Supplement §9 |
| Hero demo layout (phase 7) | The demo lays out by its own frame width with Tailwind container queries (`@container` on the frame, `@xl` / `@2xl` variants) instead of viewport breakpoints; the metric strip spans the full frame | The frame is ≈ 500 px in the two-column hero at 1024 px and ≈ 720 px at 768 px, so viewport breakpoints chose the wrong layout (docs/16 §6.1, finding F2) |
| Dashboard grids (phase 7) | Shell `grid-cols-[minmax(0,1fr)]`, `min-w-0` header with a per-breakpoint budget; `html[data-dashboard] .grid { grid-auto-columns: minmax(0,1fr) }` | An implicit `auto` grid track grows to the min-content of its items while `html`/`body` are `overflow: hidden`, which hid header actions and page content at 320–768 px (finding F1) |
| Scroll regions (phase 7) | `ScrollRegion` scroller is `position: relative` inside a `relative overflow-clip` frame and shows an edge fade while more columns follow | Absolutely positioned `sr-only` descendants escaped the scroller and widened the page (finding F3); the fade is the visible scroll affordance |
| Web fonts (phase 7) | Inter and Bricolage load the `latin` subset only; Bricolage (headings, `display: swap`, size-adjusted fallback) is not preloaded | 198 KB of preloaded fonts competed with the HTML and the render-blocking CSS on mobile; no character of the six locales' content lies in `latin-ext` (docs/16 §6.3) |
| Evidence pack (phase 7) | One dated directory `docs/qa/<date>/` with the raw tool output (Lighthouse LHR, axe JSON, crawl JSON, sweep JSONL, gate logs), WebP screenshots ≤ 150 KB, generated reports and generator scripts; every claim in a report points to a file; a check that could not run is listed as "not run" with the reason | Supplement §11 "Abschlussbelege"; reviewers can re-derive every number |
